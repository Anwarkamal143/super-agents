# Super Agents

An agent-agnostic software factory for request intake, specification, planning, implementation, verification, independent review, and human-approved delivery.

The implementation roadmap and dependency graph live in [GitHub issue #1](https://github.com/Anwarkamal143/super-agents/issues/1). The first implementation slice is [issue #2](https://github.com/Anwarkamal143/super-agents/issues/2).
